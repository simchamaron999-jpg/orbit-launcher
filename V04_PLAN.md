# Orbit Launcher 0.4 — Acceptance Plan

## Confirmed changes

| Area | Acceptance criterion |
|---|---|
| Collapsed settings | Every settings category begins collapsed. A single row with a chevron expands or collapses that category in place. No category is open by default. |
| Faster settings navigation | Categories are shown as a concise vertical list. Users do not need a horizontal category strip or a long, always-open configuration page. Opening a category exposes only its relevant controls. |
| Divider-free visual system | Bright horizontal dividers are removed from settings and the app orbit remains free of decorative separator lines. Spacing, tonal surfaces, section typography, and chevrons provide hierarchy instead. |
| Portrait-native wallpapers | Every bundled wallpaper is source-native portrait orientation. Landscape sources and the blurred/contained adaptation treatment are removed. |
| Wallpaper gallery | The gallery keeps a curated set of 12 portrait natural scenes, all previewable through the existing settings gallery and displayed without letterbox bands. |
| Visual readability | Photos remain behind a restrained opacity layer so Material 3 controls and orbit icons stay readable. |

## Scope boundary

This update implements the explicitly queued settings and wallpaper work. The wider list of future improvements—including layout presets, drag placement, notification dots, backups, and onboarding—remains a prioritised backlog rather than being added without a separate confirmation.
